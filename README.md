## `ls open-source/`

- **[Primitree](https://primitree.com)** · [repo](https://github.com/marklearst/primitree) · [docs](https://primitree.com/docs) · [playground](https://primitree.com/playground)
  Token governance toolchain. Layer rules fail the build on a literal color in a reference layer, DTCG diffs classify renames and removals as breaking for CI, and generated files refuse to be overwritten by hand edits. Six packages on npm: CLI, core, DTCG, hooks, and an MCP server so agents can query and diff tokens. Output: DTCG 2025.10, CSS, Tailwind, TypeScript.
- **[a11y Companion](https://www.figma.com/community/widget/1509302611418259130/a11y-companion)** · [repo](https://github.com/marklearst/a11y-companion-widget) · [site](https://marklearst.me/a11y-companion-widget/)
  Accessibility review widget for Figma and FigJam. 456 users on Figma Community, 20 locales, 64 WCAG checks. Findings become native Dev Mode annotations with WCAG links, and a section signoff records what it reviewed, so it goes stale when the work changes. A checked box is a claim, not a measurement.
- **[Variable Design Standard](https://variable-design-standard.vercel.app/)** · [repo](https://github.com/marklearst/variable-design-standard)
  Open spec for governing design variables on DTCG 2025.10: three layers, naming rules, reference validation, mode consistency, and breaking change detection with release notes. Primitree is the tool that enforces it.
- **[FigmaVars Hooks](https://www.npmjs.com/package/@figma-vars/hooks)** · [repo](https://github.com/marklearst/figma-vars-hooks)
  Typed React 19 hooks and a CLI for the Figma Variables REST API, 100% test coverage. The starting point for Primitree.
- **[GlucoseIQ](https://glucoseiq.dev)** · [repo](https://github.com/marklearst/glucoseiq) · [npm](https://www.npmjs.com/package/@glucoseiq/core)
  Headless TypeScript analytics for CGM data: 17 metric modules, 5 packages, zero runtime dependencies, 100% coverage thresholds, FHIR and Open mHealth output. Docs code samples run in CI, so a broken example fails the build. A watchOS app is approved and waiting on one more feature.
- **[one-more-pass](https://github.com/marklearst/one-more-pass)**
  Claude Code plugin with two skills: a final editorial pass for prose and a final review pass for code. Rule based, with a scanner that reports findings instead of guessing authorship.
