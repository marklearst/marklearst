Design systems architect and hands-on React engineer. I build the path from token contracts to production UI: typed component APIs, Storybook, accessibility, testing, release controls, and governance.

My lane is the whole system, including the product UI that consumes it. I work in code, close the gap between Figma and React, and build the checks that keep both sides from drifting apart.
